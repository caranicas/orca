## Confirmed provider constraints

These constraints were disclosed before completion-only/unknown fallbacks. They do not excuse unfinished integrations.

1. **Unrecorded history cannot reconstruct absent starts.** Codex rollout policy excludes execution-begin and several hook lifecycle records. Where neither rollout nor an observer retained an event, its start/duration remains unknown. A newly observed completed call can animate without pretending it is still running.
2. **Claude may refuse native modules.** Trust, safe/bare mode and managed policy can prevent a mod from loading. Classic hooks, status-line data and transcript data remain separate sources; use what is actually available rather than claiming the entire feature is impossible.
3. **Code-mode nesting does not retain every result.** Installed Codex records the outer JavaScript runner and inner shell with distinct call IDs. Optional executed-tool metadata is absent from the captured rollout; an inner denied attempt can have a start hook without a result. It remains unknown rather than inheriting the outer failure. The outer runner is labeled workflow and its provider-owned result header supplies success/failure/duration.
4. **Missing measurements remain unknown.** Historical Claude usage without a verified matching-model capacity cannot establish a reliable context percentage. A bare model-name capacity guess is not used. Direct status-line/native measurements take precedence when available.

Reasoning text and generic idle transitions are never proof of a model request or successful answer. Claude native model steps are provider step observations; another plugin can answer a step without making an API request.

Older Codex versions can omit model-request hooks: [CI's actual 0.150.1 binary](https://github.com/caranicas/orca/actions/runs/43762622211/job/132962161150) accepts the managed hook file but its `hooks/list` reports no `pre_model_request` or `post_model_request`. Its advertised hooks still undergo the full file-entry hash/trust contract. Explicit transcript responses remain usable where present; missing starts remain unknown. This is version-specific provider evidence, not a missing-reader justification. A read-only isolated probe of installed 0.169.0 reports all 13 managed hooks, including both model hooks, and its cross-position hash contract passes on Windows. The native Windows default-home fixture cannot redirect Known Folder lookup with HOME/USERPROFILE; its full real-home sub-suite is not claimed to pass locally.

Codex 0.169 native raw-response notifications are opt-in. The installed source exposes experimentalRawEvents on ThreadStartParams, omits it from ThreadResumeParams, and filters RawResponseCompleted while that thread flag is false: protocol/v2/thread.rs and app-server/src/request_processors/thread_lifecycle.rs at the installed-version commit below. The observed resumed native chat had no raw-response journal facts. This is an API boundary, not a missing-reader impossibility: its rollout still reports response IDs and model settings, and the native panel now reads those through the existing owning-host transcript reader. An isolated real thread/start probe also confirms that Codex reports its new transcript path before its first model request. Older hosts without the optional source ID/path retain available journal data.

## Intentional Orca equivalents and visible differences

- The map opens with Orca's terminal button and resizable split. It does not add upstream's /lot-map command to the user's terminal input.
- It uses SVG beside the terminal, with Lucide icons and Orca typography/resting/error tokens as required by STYLEGUIDE.md. It is not a terminal-cell raster; cellShape has no corresponding effect. Hide/show provides the text-only/picture equivalent.
- Default memory path mappings additionally recognize Orca's agent instruction files; this differs from upstream's empty configurable memoryPaths default.
- Reduced motion stops clocks as well as decorative travel/spinning, following the app's accessibility behavior. Upstream retains its slow clock hands.
- Explicit unknown/interrupted/failed distinctions and estimate markers are retained even where upstream settles an unreported outcome optimistically.
- Added telemetry is optional for old peers. Missing capability or evidence degrades to unknown/available history, not invented live data.
